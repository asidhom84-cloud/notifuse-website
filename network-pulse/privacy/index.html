Network Pulse: NOC

Privacy Policy

Effective date / Last updated: September 20, 2026

This Privacy Policy describes how Network Pulse: NOC (the store listing name), shown inside the app as Network Pulse, handles information when you use the mobile application. Network Pulse is operated by Amir Sidhom. Noti Family is the marketing name for the family of apps that includes Network Pulse; it is not a separate legal entity.

Application identifiers:

  • Android package: com.amirsidhom.networkpulse
  • iOS bundle ID: com.amirsidhom.networkpulse

This policy is specific to Network Pulse. Other Noti Family apps have their own legal pages. This page is public: you do not need an account, cookies, or the app installed to read it.

About Network Pulse

Network Pulse is an internal network-operations mobile app. It helps authorized users view network operational status, synchronized reports, down-site information, and related tools such as Nearby Down Sites.

Network Pulse is not a consumer social app, does not show advertising, and is not affiliated with any third-party telecom operator brand.

Information We Access

Depending on how you use Network Pulse, the app may process:

  • Sign-in credentials. A username and password that you enter to authenticate. The password is sent only to the authentication service during sign-in and is not stored in the app’s local preferences storage.
  • Account identity returned after sign-in. A username and display name associated with your session, plus a time-limited access token used to call Network Pulse services.
  • Precise location (optional, foreground). When you use Nearby Down Sites and grant permission, the app reads your current device location once (not continuously in the background) to find down network sites near you. See “Location Information” below.
  • Network and connectivity state. Basic online/offline status so the app can refresh a signed-in session when connectivity returns.
  • Operational and report content. Network status, down-site and site-detail records, and public report datasets that the app downloads for display and offline cache.
  • App settings you choose. For example appearance (light/dark) and the Nearby Down Sites search radius.
  • Files you export. If you export a down-sites spreadsheet, the file is written to the app’s on-device cache and can be shared through the system share sheet.

Network Pulse does not include advertising SDKs, analytics SDKs, or crash-reporting SDKs in the current mobile app dependencies.

Location Information

Network Pulse uses location to calculate and show Nearby Down Sites — down network sites around your current position.

What the app does:

  • Requests foreground / when-in-use location permission (Android fine and coarse location permissions are declared; the app requests fine location for a precise fix; iOS uses When In Use).
  • Reads a one-shot current position while you are using the Nearby Down Sites feature (for example on screen load, when filters change, or when you refresh).
  • Does not implement background location tracking, continuous GPS watching, or Always location authorization in the app’s code.

Does precise location leave the device? Yes. When Nearby Down Sites runs, your latitude and longitude are sent as query parameters — together with your chosen radius and optional filters — to the Network Pulse API so the service can return nearby down sites. The request is authenticated with your session token.

You can deny or revoke location permission in system settings. Without permission, Nearby Down Sites cannot obtain your current position.

How Information Is Used

  • Authenticate authorized users and keep a signed-in session.
  • Fetch and display network operational status, site details, alarms, and related data.
  • Compute and display nearby down sites using your current location.
  • Synchronize and cache public report datasets for offline/faster viewing.
  • Remember preferences such as theme and nearby search radius.
  • Support optional export/share of down-site spreadsheets from the device.

Information Stored on the Device

Network Pulse stores information locally on your device, including:

  • Session access token in the device secure storage (Keychain on iOS / Keystore-backed storage via the app’s keychain library on Android).
  • Username and display name for the signed-in identity.
  • Theme preference and Nearby Down Sites radius preference.
  • Cached public report data (departments, reports, report details), data version, and last-synced timestamp.
  • Temporary exported spreadsheet files in the app cache when you use export.

Logging out clears the session token, stored identity, and cached report data. Some preferences (such as theme or nearby radius) may remain on the device until you clear app data or uninstall.

Network and Report Data

Network Pulse communicates over HTTPS with services used to operate the product:

  • Authentication service hosted on Google Cloud Run — sign-in, session check, and logout.
  • Network Pulse API hosted on Google Cloud Run — operational status, down sites, nearby down sites (including your coordinates when that feature is used), site details, and spreadsheet export.
  • Public report data retrieved from application backend services and a static data-hosting service used by Network Pulse, published as versioned JSON files (for example version, department, report, and report-detail listings).

Opening an external report link or map link uses your device’s system browser or maps app. Network Pulse does not embed an in-app web browser for those links.

Third-Party Services

In providing Network Pulse, information may be processed by:

  • Google Cloud Run — hosts the authentication and Network Pulse API backends that receive authenticated requests (and location coordinates when Nearby Down Sites is used).
  • GitHub Pages — hosts the public static report JSON files the app downloads.
  • Apple / Google — platform services involved in installing the app, system permissions, secure storage, and (if you distribute via their stores) store infrastructure.

Those providers process technical request data as needed to host and deliver the service (for example connection metadata). Their own privacy policies apply to their platforms.

Network Pulse does not use third-party advertising networks or third-party product analytics SDKs in the current app.

Data Sharing

We do not sell personal information.

We share information only as needed to operate Network Pulse:

  • With the backend services described above, to authenticate you and return operational/report data.
  • With your location coordinates, only when you use Nearby Down Sites with location permission granted.
  • When you choose to share an exported file through the system share sheet, with the destination you select.
  • If required by law or to protect the security and integrity of the service.

Data Retention

On the device, session and cache data remain until you log out, clear app storage, or uninstall, subject to the logout clearing behavior described above.

Server-side retention for authentication and Network Pulse API records is governed by the operators of those services and is limited to what is needed to provide access and operational functionality to authorized users. This policy does not invent specific server retention periods beyond that operational purpose.

Security

Network Pulse uses HTTPS for network communication and stores the session token in the device’s secure storage mechanism provided through the app’s keychain library. No method of transmission or storage is completely secure. Please protect your device and credentials.

Children's Privacy

Network Pulse is intended for authorized adult users in an operational/work context. It is not directed to children under 13, and we do not knowingly collect personal information from children under 13.

User Choices and Permissions

  • You can deny or revoke location permission in system settings.
  • You can log out from Settings to clear the session token, stored identity, and cached report data.
  • You can clear app storage or uninstall the app to remove remaining on-device data.

Accounts. Network Pulse supports sign-in for authorized usernames. The app does not provide self-service account registration, and it does not provide an in-app account-deletion feature. If you need help with account access or removal of account-related data held in backend systems, contact us using the address below.

Changes to This Policy
